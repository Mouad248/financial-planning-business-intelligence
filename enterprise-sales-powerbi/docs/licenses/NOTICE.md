# Data source attribution

The invoice-line data and business dimensions derive from Microsoft's fictitious Wide World Importers sample, recovered from this archived report's cached model. Entity names were replaced with neutral labels and contact values removed; keys and financial values were retained. Budgets and salesperson targets are synthetic planning inputs.

Official sample: https://github.com/microsoft/sql-server-samples/tree/master/samples/databases/wide-world-importers

The Microsoft SQL Server Samples license is preserved in MICROSOFT_SAMPLE_LICENSE.txt. Required source/copyright attribution is retained.
